# 技术栈与项目作品

模板不预置技术或项目条目。请在编辑空间填写自己的作品、技术名称和说明；技术栈不自动推断个人资历或熟练度。

- 首页的技术栈和开源项目入口分别打开 `#tech`、`#projects` 专属展示页。顶部旧栏目导航不恢复；返回主页、Esc、直达哈希和浏览器历史共用原有路由。
- 项目卡片展示界面示意、介绍、功能亮点、技术标签和源码状态。示意图为代码绘制，外设电量为说明用样例，不读取当前电脑设备。上传项目图片后优先显示图片。无仓库链接时显示“源码暂未公开”，不生成下载、GitHub、star 或许可证信息。
- 技术按分组展示，点击选中后显示实践说明及关联项目。关联依据项目 `stack` 里逗号/分号/换行分隔的完整技术名称；项目标签可反向进入对应技术。文字与 URL 只使用安全 DOM/API，本地图片遵循公开媒体文件名校验。
- 内容存入既有公开 `tech`、`projects` 栏目，全部字段可从编辑空间管理。展示页无增删改入口。空数据保持空展示，不从源码偷偷补回已删除条目。
- 测试中的样例仅用于验证显示行为，不会写入用户数据库。没有自动导入作者作品的脚本。
- 新增 `public/work-showcase.js/css` 随公开主页离线导出。不加载外部字体、图标、图片库或项目仓库。背景保留，页间空隙可与壁纸交互，可见卡片和控件接收前景操作；动效有限，并支持减少动态效果。
