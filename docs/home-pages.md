# DIY 页面接入约定

当前仍显示原有四页；本次只预留页面管理能力，不增加 DIY 新增按钮或保存接口。

## 页面来源

`#content` 的直接子元素中，带 `data-home-page` 和唯一 `id` 的节点组成分页列表，顺序即 DOM 顺序。
`aria-label` 作为页面名称；没有名称时使用“第 N 页”。不再在分页脚本或路由中维护四个页面的固定数组。

后续 DIY 编辑器从持久化配置渲染页面节点后，调用 `window.HomePages.refresh()` 即可重新生成圆点。
新增、重排、删除都通过同一个入口同步，`homepages:changed` 事件会通知路由刷新。
现有页面保留稳定 ID，尤其是 `about`，因为个人资料布局编辑入口仍以它为目标。

```js
// 示例：由未来的 DIY 页面管理器创建节点，实际保存由页面配置层实现。
const page = document.createElement('section');
page.id = 'diy-gallery'; // 配置生成的稳定、唯一 ID，不能每次渲染变化。
page.className = 'hero blank-page';
page.setAttribute('data-home-page', '');
page.setAttribute('aria-label', '我的展示页');
const heading = document.createElement('h2');
heading.className = 'sr-only';
heading.tabIndex = -1;
heading.textContent = '我的展示页';
page.append(heading);
document.getElementById('content').insertBefore(page, document.getElementById('home-pagination'));
window.HomePages.refresh();
```

`HomePages.ids` 返回页面 ID 数组的副本；`HomePages.label(id)` 获取名称。
新增页自动参与圆点、左右键、横向手势、哈希与历史导航。页数较多时导航横向滚动，选中的圆点保持可见。
删除当前页的 DOM 节点并刷新后，路由回到剩余第一页，不保留指向已删除页的当前 URL。
页面配置的后端校验、保存与导出仍需在正式制作 DIY 页面管理时接入；该接口本身不写用户数据。

## 动画约定

### 独立音乐展示页

- `#music` 是专属展示路由，不占用四个横向分页。入口层级固定为“主页 → 兴趣收藏 → 爱听的音乐”，首页不单独添加音乐条。音乐页的返回按钮和 Esc 返回兴趣收藏，再返回主页；浏览器历史仍按访问顺序处理。
- `MusicWall.render(publicEntries)` 只使用公开 `music` 数据；`MusicWall.setActive(boolean)` 由路由通知激活或离开。歌曲内容仍在编辑空间管理，当前只通过安全 HTTP(S) 收听链接外跳，没有站内音频、自动播放或全屏歌词。
- 首屏改用参照视频/截图测量的固定横向模板，不再根据密度随机生成：9×5 格的窗口共 23 个封面，中间主方块 3×3（位于第 4–6 列、第 2–4 行），右上宽幅封面 3×2，顶部两条 2×1、两个小方块，左侧两个 1×1.5 竖块及一横条/四小块，右侧两小块和两竖条，底部依次为 1.5、3、1.5、1、1、1 格宽的横向组合。初始窗口有 11 个固定小正方形，屏幕间距 4px。
- 23 仅为参照首屏的数量，不是总数。模板左、右各延伸三列，上、下各延伸一行，默认空白预览共 61 个封面、画布 15×7 格；上下左右均有可浏览的屏外封面。真实集合超过基础容量后用完整的侧翼和上下边条继续延展，不重复真实歌曲、不变动焦点锚点。少量真实数据只占自己的格位，不生成虚构条目。
- 音乐画布保留 1.12 的逻辑/屏幕坐标换算，格距按首屏 9×5 横向窗口计算，而不是把整个 15×7 画布缩进屏幕。常规横屏基本对齐参考可见格数；窄屏及超宽屏保持正方形比例、通过平移浏览，不强行拉伸。画布比视口大，可用拖动、滚轮、Shift+滚轮或鼠标位置跟随浏览。壁纸和左上角浮动返回按钮不缩放，音乐标题保留给辅助技术，不遮挡顶部封面。
- 屏幕位置与画布位置双向换算：拖动和滚轮按屏幕距离操作，动画中断采样除以镜头倍率，边界、初始居中和焦点露出均按逻辑视口计算。
- 鼠标位置直接映射有限的镜头目标位置，不再按边缘输入累加速度，无中心死区或点击后 720ms 暂停。跟随幅度为完整映射的 0.7 倍，响应时间常数 65ms，避免大幅牵动画面；全画布仍可通过拖动和滚轮浏览。按实际帧间隔平滑，在 30/60/120fps 下保持一致；误差小于 0.15 屏幕像素时吸附到目标并停帧。鼠标静止后镜头停在该目标，不继续漂到边界。
- 指针进入、拖动结束、滚轮操作及显式露出焦点后，重新校准跟随起点；同一鼠标位置不会把手动浏览结果拉回旧位置。按下冻结跟随以保证点击/拖动准确，松开后下一次鼠标移动立即跟随；触屏只用拖动浏览，减少动态效果时关闭鼠标跟随，离开画布、窗口失焦或隐藏页面会取消镜头帧。
- 每次选中进入同一个焦点位，旧主封面按来向退到另一侧的固定小正方形。保留初始参考模板；后续切换只改完整的邻接区域：从左选入时左侧 2×3 区域转为竖条/小块，从右选入时右侧两个竖条转为横条，从上选入时底部相邻两块借半格形成小方块出口，从下选入时底部前三块换成 2、3、1 格宽。各局部区域面积和封面数量恒定，结束严格铺满；右上宽幅地标和焦点锚点不动。
- 保留当前封面与格位的对应关系；先锁定没有变化的矩形，再对剩余局部封面做最小位移匹配以补齐空位。正常切换最多改变 12 个封面，外围除新点击封面的原格位外均不重排。重复点击无变化；重新选回进入同一主方块，但不会为恢复历史而把其他封面全局重排。不保存每个封面的整墙历史，刷新、离开及数据重排按条目 ID 保持现有空间位置；数量或视口变化时重建正规格位。
- 680ms 动画连续改变位置和宽高，不缩到零、不拉伸图片。新旧主封面沿来向保持先后关系；相邻点击时两者共用一条移动边界，间距始终为 4 屏幕像素。所有封面使用同一动画时间起点，避免接缝相位差；其他补位封面允许短暂分层交错，结束时严格保持无重叠、无洞的网格。中断先读取实际显示边界，再取消旧动画，从当前显示位置继续（可能同时收尾上一轮未完成的补位）；减少动态效果和无动画 API 时直接提交布局，离开、隐藏、重渲染时取消动画并清除临时层，无空闲帧循环。焦点已在视口内时相机不动，离开视口后再次选中才平滑露出焦点。
- 进场不再让整页平移淡入，而是按录屏中的左到右节奏逐块弹出：每个当前可见封面围绕自身中心从 84% 尺寸出现，轻微超过至 102.5%，回到 99.7% 后稳定为 100%；单块 440ms，按列 30ms/行 10ms 错峰，延迟上限 280ms，主方块稍后出现。动画使用真实宽高及位移，不拉伸图片，屏外封面不做无意义进场。每次真正进入音乐路由播放一次，重复激活、刷新及标签恢复不重播；首次数据延迟到达时等布局就绪再启动，连点从当前可见边界继续换位。减少动态效果、页面隐藏、尺寸变化或退出会清理临时层，空闲不保留动画或帧循环。
- 微交互只改变封面内部，不移动或缩放拼图外框：精确鼠标悬停时图片轻放大至 101.8%、略提亮，标题上移 2px；按下时图片缩至 98.8%、标题下移 1px，松开有轻微回弹。开始拖动后取消按压并停用悬停反馈，指针取消/丢失捕获、失焦、隐藏、退出及重渲染都清理状态。Enter/空格保留原生按钮激活，减少动态效果时取消位移及过渡，不影响已有换位和镜头规则。
- 音乐页增加不接收指针的淡主色氛围层，位于封面画布之后，仅对当前选中、已加载的安全本机封面做一次 16×16 离屏取样。排除白边、黑底和近灰色，聚合同色区，RGB 缓存上限 64 项、共享专辑复用，只有一个取样缓冲；切换主色用 620ms 过渡，空闲不运行帧循环。延迟加载的旧封面不能覆盖当前主色；未加载保留上一色，缺失/失败/像素不可读回到中性绿。隐藏或退出不取样、不显示该层，不读取壁纸像素、不复制或重载壁纸，不联网、不写歌单或浏览记录。
- 自有封面仍通过编辑空间上传并使用安全的公开媒体文件名，展示页不新增上传/删除按钮，也不接音频。首屏封面（包括底部几行）优先加载并异步解码，屏外封面保持惰性加载；加载失败回到原占位样式，不从外部地址自动抓取或引用私人图片。
- 每条真实数据只显示一次。空内容仅生成完整模板和屏外区域的空白封面预览，不填入虚构歌曲、不写入数据、不增加播放功能；基础预览可用 `MusicWall.capacity(width,height)` 查询容量（正尺寸返回 61）。
- `body.music-view` 只在音乐路由上存在，用现有 `.pond-stage::after` 对壁纸模糊和压暗；不复制、重载或替换 iframe。离开移除状态并恢复清晰。音乐画布全屏接受浏览手势，浮动返回按钮单独接收点击，不向壁纸伪造或转发前景操作。
- `music-wall.js/css` 已加入公开离线导出资源清单。

### 交互边界

- `#content`、`[data-home-page]` 和顶栏排版容器不接收指针，空白处直接交给原有壁纸 iframe；触屏也不再禁用壁纸。
- 个人卡片、地图卡片及 `[data-space-module]` 在实际可见卡片范围内接收操作。未来新增 DIY 模块应带此属性，不要给整页恢复 `pointer-events: auto`。
- 顶栏仅链接、按钮和输入控件接收操作；分页圆点保留 32 × 44 的点击区，不缩成视觉小圆点。
- 卡片里的普通区域仍支持横向翻页；按钮、地图、照片拖动区不参与翻页。壁纸空白处的拖动只操作壁纸，不同时翻页；纯空白页通过圆点切换。
- 弹窗保持模态隔离，透明不等于点击穿透；不向隔离壁纸伪造或转发前景按钮事件。

- 圆点位移、轻微拉伸和拖尾共用一个按时间计算的 520ms 进度，与前景页使用相同缓动。
- 位置取实际按钮中心，不假设四页或固定间隔。反向中断从上一次绘制位置继续。
- 拖尾最长 14px，峰值透明度 0.32，左右对称；不使用独立延迟追赶，跨页不会拉成长条。
- 减少动态效果、隐藏页面、退出及尺寸变化时停止动画并清理尾迹；空闲时不运行帧循环。
- 背景 iframe 不属于前景分页动画，也不因切换或新增页面重新加载。

## 照片集模块

第二页目前挂载 `#photo-album[data-space-module="photo-album"]`。卡片及折页 CSS 使用模块类名，不依赖第二页的 ID；后续可将模块节点搬到其他 DIY 页面。
当前尚未接入跨页拖拽和布局持久化，不应把 `data-space-module` 当成已经可拖动的承诺。

`PhotoAlbum.render(root, entries)` 只渲染公开 `gallery` 栏目；图片仅引用 `/media/public/`，离线导出使用相对路径。
私人 `photos` 栏目完全独立，不自动复制或展示。展示照片在编辑空间的“展示照片集”中上传、编辑、排序。
卡片内 `data-page-gesture-lock` 隔离照片浏览手势，不会切换整个页面。
照片按用户审核的第一张样图（`exec-4ca85ebc-226b-42de-b189-8d56a1da669a.png`）排列：中心基本正对视线并前凸，左右照片朝向镜像对称，沿浅 U 形向两侧逐渐退后、抬高、缩小。不是第二张高俯视方案，也不再全体朝同一方向倾斜。支持的浏览器显示淡倒影，不创建额外图片副本。
支持滚轮、捕获指针后的横向拖动及左右键，停止输入后自动对齐最近照片；五张以上循环轮换，少量照片在端点停止，不复制凑数。
空相册提供九张透明轮廓用于体验交互，不包含示例照片；没有照片点击展开或详情弹窗。
帧循环只在输入后的缓动期间运行；页面隐藏、离屏或组件重渲染会停止动画、清除计时器并释放旧观察器。
