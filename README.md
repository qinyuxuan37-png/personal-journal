# Personal Journal · 空白 DIY 个人空间

一个在本机运行的个人展示与记录模板。保留交互和编辑功能，不附带作者的资料、歌单、音乐封面、照片、项目条目或 Wallpaper Engine 壁纸。首次启动所有内容集合为空，由你自己 DIY。

## 启动

需要 Python 3.10 或更高版本，无须安装第三方 Python 包。

```sh
python server.py --open
```

Windows 也可以双击 `启动网站.cmd`。浏览器访问 `http://127.0.0.1:8765`；在「编辑空间」填写自己的资料和内容，在「DIY 空间」配置布局、开场及背景。关闭终端即可停止服务。不要直接双击 HTML 作为编辑入口。

## 保留的功能

- 公开个人资料、技术栈、项目、兴趣收藏与社交主页链接。
- 多页切换、可调整布局、开场动画、半透明界面。
- 可导入照片的相册，以及支持封面、选中放大和视角移动的音乐墙。
- 私人记录、图片上传、备份与公开内容静态导出。
- 离线地图；天气需自行启用联网。
- 可选本地网页壁纸和场景壁纸兼容播放接口。

空白占位结构用于预览布局，不是预置作品。音乐功能展示用户添加的封面和链接，不提供曲库、音乐下载或自动获取播放版权。

## 壁纸由使用者自行添加

模板不附带任何创意工坊壁纸，也不会自动扫描整个电脑。打开「DIY 空间 → 背景 → 导入其他文件夹」，选择自己已有的可信壁纸目录。网页壁纸需要有效 HTML 入口；场景壁纸需要 `project.json` 和 `scene.pkg`。视频和应用程序壁纸暂不支持。

场景由 WebWallGL 兼容渲染，效果不保证与 Wallpaper Engine 一致。无需壁纸也能使用模板。Wallpaper Engine 不是本项目的一部分；本项目不会修改其桌面选择。配置和个人媒体仅保存在本机，不要提交到仓库。

## 数据与安全

首次运行会自动建立空白 `data/`，其中公开和私人 SQLite 数据库及媒体分开保存。`data/` 和 `wallpaper.*.json` 已被 Git 忽略。克隆此仓库不会得到作者的本机内容。

**服务只用于本机，监听 127.0.0.1，没有账户认证或数据加密。请勿通过端口转发、反向代理或修改监听地址把管理接口公开。**「公开」指展示内容分类，不代表本机服务器适合直接上线。需要分享页面时使用静态导出，并先核查其中的资料和媒体是否愿意公开；私人备份也不要上传。

第三方壁纸可执行脚本，只导入可信来源。请自行确认上传的图片、封面、音乐和其他素材具有相应使用权限。

## 开发与测试

后端使用 Python 标准库与 SQLite；前端使用原生 HTML、CSS、JavaScript。Node.js 22+ 仅用于测试。

```sh
python -m unittest discover -s tests -p "test_*.py"
node --test tests/*.mjs
```

PowerShell 可用 `node --test (Get-ChildItem tests/*.mjs).FullName`。测试使用临时数据或内存夹具，不导入作者内容。

目录：`public/` 展示界面；`studio/` 编辑界面；`server.py` 本机 API；`tests/` 回归测试；`scripts/` 离线地图构建工具；`docs/` 交互说明。
